# 受洗禮拜服事指南（現代極簡向量圖版）

## 更新亮點
1. **100% 高解析向量圖（SVG）重繪**：移除所有原始截圖的 Excel 網格線與手機黑邊，採用現代企業級扁平向量設計，手機或電腦任意放大都不失真。
2. **精準還原原始配置**：完整保留聖餐台前 8 人站位、A～F 區座位數（A區71位、B區28位、C1區38位、C2區63位、D區30位、E區25位、F區左84位/右115位）、大親子室、親子室、音控台、影音區、回程順序（5-6-7-8-1-2-3-4），以及姊妹（女1～女4）與弟兄（男1～男8）站位方向。
3. **個人化互動高亮**：點擊任一同工卡片跳出 Pop-up 詳情時，卡片內附帶的站位與動線圖會**自動高亮該位同工的專屬位置與路線**。

## 部署方式
解壓縮後，將 `index.html` 直接上傳至 GitHub Pages、Netlify、Vercel、Cloudflare Pages 或教會網頁主機即可（無需額外外部圖片檔，載入速度極快）。
