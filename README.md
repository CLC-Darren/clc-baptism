## v4 更新重點
1. **分頁順序調整**：
   - **第一頁（預設開啟）**：`受洗招待服事同工`
   - **第二頁**：`聖餐服事同工`
2. **版面順序調整（場地圖置頂、同工名單在下方）**：
   - 無論在「受洗招待」或「聖餐服事」頁面，皆將**整個場地與站位動線圖置頂放前面**，同工名單卡片緊接在下方，方便同工先看全場方位再找個人職責。
3. **場地圖站位標註全面加上互動超連結**：
   - 在招待站位圖上直接點擊任意標註（`女1`～`女4`、`男1`～`男8`），或在聖餐動線圖上直接點擊任意站位圓圈（`1`～`8`），皆會**直接開啟該同工的 Pop-up 詳細服事卡片**（點擊 `男6、7、8` 走廊區域時，彈窗頂部還可一鍵切換三人各自負責的走廊路段）。
